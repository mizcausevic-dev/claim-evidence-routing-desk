# Security Policy

This repository is a public demonstration surface using **synthetic claim and packet data only**.

## Scope

- No live PHI, payer data, member data, reimbursement records, or production appeals should be committed here.
- The repo demonstrates routing and evidence posture patterns, not a production insurance claims platform.

## Disclosure

If you identify a security issue in the code or deployment workflow, please open a private report through GitHub Security Advisories if available, or contact the repository owner directly.

## Operational note

This project is **not** represented as HIPAA-, HITRUST-, SOC 2-, or payer-audit compliant by default. Any production adaptation would need formal review, data-handling controls, and environment-specific hardening.
